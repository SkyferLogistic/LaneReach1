## Scripts library

Marketing keeps each outreach email as a **Word file per language** in the scripts library (SharePoint, or a local folder in development), for example `Scripts/Air/Intro/Turkish.docx`. LaneReach syncs the library every few minutes and turns each file into a template. Edit in Word; LaneReach picks up the change.

The **Scripts** page shows the script × language matrix: live, AI draft, missing, held or error per cell. Click a cell to see exactly what a contact receives.

## Missing languages

When a language is missing, you can ask the AI to draft a translation from an existing version. An AI draft is never sent until a person approves it.

## Placeholders

Scripts use placeholders such as `{{contact.first_name}}`, `{{company.name}}`, `{{office.name}}` and `{{to_country}}` (the destination written the way that language says it).

## Banners and brand images

Banners per service line and country (`Banners/Air/TR.png`) and brand images (`Brand/logo.png`, `Brand/badge-*.png`) come from the same library.
