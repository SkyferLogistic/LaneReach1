## Import

Import a CSV file of up to 5,000 rows on the Contacts page. You can add a tag to every imported contact; a tag can start a workflow (*Tag added* trigger).

## Stages

Each contact has a funnel stage (new, contacted, engaged, qualified, customer, partner, not interested, do not contact). Replies move contacts automatically (for example a rate request makes them *qualified*), and workflows can change the stage.

## Email verification

*Verify email* checks an address (with MillionVerifier when connected, otherwise offline rules). Invalid addresses are blocked by the *email verification* guardrail; risky ones are only flagged.

## Bulk actions and views

Select contacts to add a tag, verify their emails or erase them. Save filter views for yourself.

## Erasing a contact (GDPR)

Admins can **erase** a contact: the contact and every copy of their data (messages, enrollments, quote requests, deals, meetings, notes) are deleted, and the address stays **suppressed** so a later import never emails them again. You confirm by typing the address.

A company with contacts cannot be deleted; move or erase the contacts first.
